# Glossary

Acronyms and terms used across this repository. I expand it as I go.

## SOC and detection
- **SOC** — Security Operations Center. The team that monitors, detects and responds to incidents.
- **SIEM** — Security Information and Event Management. Centralizes and correlates logs.
- **EDR** — Endpoint Detection and Response.
- **Sysmon** — System Monitor. Detailed Windows telemetry (processes, network, registry).
- **Sigma** — Open detection-rule format, convertible to KQL, SPL, etc.
- **IOC / IOA** — Indicator of Compromise / of Attack.
- **Triage** — First review of an alert: false positive, close, or escalate?

## Attack and reference framework
- **MITRE ATT&CK** — Knowledge base of adversary tactics and techniques.
- **Atomic Red Team** — Public library of security tests for defensive teams.
- **Purple team** — Exercise where an attack is simulated and detection is measured.

## Forensics
- **DFIR** — Digital Forensics and Incident Response.
- **Timeline** — Chronological reconstruction of what happened on a system.
- **Volatility** — Memory forensics framework.

## AI and its security
- **RAG** — Retrieval-Augmented Generation.
- **MCP** — Model Context Protocol.
- **Guardrail** — A control that filters the inputs or outputs of an AI system.
- **Prompt injection** — An attack that manipulates a model's instructions through its input.
- **Eval** — Systematic evaluation of an AI system's quality and safety.
